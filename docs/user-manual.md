## 1. 系统访问

### 1.1 访问方式

| 环境 | 地址 | 说明 |
|------|------|------|
| **Web 前端** | `http://localhost:3000` | 完整功能界面 |
| **API 网关** | `http://localhost:8080` | 后端 API（开发者使用） |

### 1.2 系统要求

- **浏览器**: Chrome 90+、Edge 90+、Firefox 90+（支持 SSE 流式输出）
- **分辨率**: 建议 1280×720 以上
- **网络**: 内网连接即可，无需互联网

## 2. 登录与权限

### 2.1 首次登录

1. 打开浏览器访问 `http://localhost:3000`
2. 进入登录页面，使用默认管理员账号：

   | 字段 | 值 |
   |------|------|
   | 用户名 | `admin` |
   | 密码 | `admin123` |

3. 登录成功后进入智能问答主界面

> ⚠️ **安全提醒**: 生产环境部署后请立即修改默认管理员密码！

### 2.2 用户角色

| 角色 | 权限 | 说明 |
|------|------|------|
| **管理员 (admin)** | 全部权限 | 创建知识库、管理用户、查看所有内容 |
| **编辑者 (editor)** | 读写权限 | 上传文档、问答、编辑知识库 |
| **用户 (user)** | 只读 | 仅可发起问答 |
| **查看者 (viewer)** | 受限只读 | 仅可查看已分配的文档内容 |

### 2.3 权限配置

管理员在管理后台进行用户管理操作（参见第 6 节）。

## 3. 知识库管理

### 3.1 创建知识库

1. 点击左侧导航栏中的"知识库管理"
2. 点击右上角的"新建知识库"按钮
3. 填写知识库信息：

   | 字段 | 说明 | 示例 |
   |------|------|------|
   | 名称 | 知识库显示名称 | "产品技术文档" |
   | 描述 | 知识库用途说明 | "包含产品的安装、配置和运维文档" |
   | 访问级别 | 公开/私有 | 公开（所有人可查看） |

4. 点击"创建"，完成

### 3.2 知识库列表

知识库管理页面展示所有知识库：

- 名称与描述
- 文档数量
- 创建时间
- 操作按钮（进入/编辑/删除）

### 3.3 删除知识库

1. 在知识库列表中定位目标知识库
2. 点击"删除"按钮
3. 确认删除（**此操作不可撤销**，知识库中所有文档和索引将被清除）

## 4. 文档管理

### 4.1 支持的文档格式

| 格式 | 文件后缀 | 说明 |
|------|---------|------|
| PDF | `.pdf` | 通用文档格式 |
| Word | `.docx`, `.doc` | Microsoft Word 文档 |
| Markdown | `.md` | 技术文档、README |
| HTML | `.html`, `.htm` | 网页文件 |
| 纯文本 | `.txt` | 简单文本文件 |

> 每个文件最大 50MB，超出部分将被拒绝。

### 4.2 上传文档

1. 进入目标知识库
2. 点击"上传文档"按钮
3. 选择本地文件（支持拖拽上传）
4. 等待上传进度提示
5. 系统提示"文档已加入索引队列"后，文件进入后台处理

### 4.3 文档索引状态

上传后文档会经过以下处理阶段：

```
上传完成 → 队列中 (queued) → 处理中 (processing) → 已完成 (completed)
                                                      └→ 失败 (failed)
```

状态说明：

| 状态 | 图标 | 说明 |
|------|------|------|
| `queued` | ⏳ | 文档已入队，等待 Worker 消费 |
| `processing` | 🔄 | 正在解析、分块、向量化 |
| `completed` | ✅ | 索引完成，可被检索到 |
| `failed` | ❌ | 处理失败（查看日志定位原因） |

可通过刷新文档列表或查看文档状态接口获取最新状态。

### 4.4 管理文档

文档列表展示：

- 文档标题和类型
- 上传时间
- 索引状态
- 操作按钮（查看/删除）

**删除文档**：从知识库中移除文档及其所有向量索引。

## 5. 智能问答

### 5.1 发起对话

1. 在知识库页面点击"进入问答"
2. 或从首页直接选择知识库后进入对话界面
3. 在底部输入框中输入问题，按 Enter 或点击发送按钮
4. 系统将以流式（打字机效果）输出回答

### 5.2 流式输出

- 回答内容会逐个 Token 实时显示
- 支持 Markdown 渲染（标题、列表、代码块、表格等）
- 回答完成后显示来源引用

### 5.3 来源引用

每个回答底部的"来源"区域展示引用的文档片段：

```
📄 来源：产品部署指南.pdf
相关度评分: 0.89
原文内容: "系统的默认端口为 8080，如需修改请编辑 config.yaml"
```

- 点击来源可展开查看完整原文片段
- 每个关键观点后标注 `[Doc-N]` 引用编号
- 系统根据向量相关性和 BM25 关键词匹配综合排序

### 5.4 对话历史

- 系统自动保存每轮对话（用户问题 + AI 回答）
- 左侧历史列表可浏览和切换不同对话
- 支持删除历史对话
- 长对话自动压缩摘要（超过 6 轮时，旧轮次被压缩为摘要保留关键信息）

### 5.5 智能问答 API

如需通过 API 调用，使用以下格式：

```bash
POST /api/v1/knowledge-bases/{kbId}/chat
Content-Type: application/json
Authorization: Bearer <token>

{
  "question": "如何配置数据库连接？",
  "conversation_id": "可选，留空则创建新对话",
  "history": []
}
```

响应为 SSE (Server-Sent Events) 流式输出：

```
data: {"type": "token", "content": "系统"}
data: {"type": "token", "content": "的数据"}
data: {"type": "done", "conversation_id": "xxx", "sources": [...]}
```

## 6. 管理后台

### 6.1 系统统计

管理员可以通过 `GET /api/v1/admin/stats` 查看系统运行状态：

| 指标 | 说明 |
|------|------|
| 知识库数量 | 已创建的知识库总数 |
| 文档数量 | 已上传的文档总数 |
| 文档块数量 | 向量化后的文本块总数 |
| 用户数量 | 注册用户总数 |
| 对话数量 | 产生的对话总数 |
| 系统运行时间 | 服务持续运行时间 |

### 6.2 监控端点

管理员和运维人员可查看以下监控端点：

| 端点 | 说明 | 访问权限 |
|------|------|---------|
| `/health` | 服务健康状态 | 公开 |
| `/health/llm` | LLM 连接状态 | 公开 |
| `/health/downstream` | 下游服务状态 | 公开 |
| `/metrics` | Prometheus 指标 | 内部网络 |

## 7. 常见问题

### Q: 上传文档后搜索不到相关内容？

**可能原因**:
1. 文档索引尚未完成（状态为 `processing`），请等待
2. 文档索引失败（状态为 `failed`），请联系管理员查看日志
3. 问题与文档内容不相关，尝试换一种表述方式
4. 文档格式不受支持，参考第 4.1 节支持的格式列表

**正常流程**: 小文件（< 1MB）通常在 30 秒内完成索引。

### Q: 回答内容不准确或编造信息？

**系统机制**:
- 系统强制要求基于知识库内容回答，无法回答时明确告知
- 每个回答都附带来源引用，可追溯信息来源
- 如果回答没有引用来源，说明 LLM 可能产生了幻觉，请通过管理员反馈

**建议操作**:
1. 检查知识库中是否有相关文档
2. 尝试更精确地描述问题
3. 确认文档内容是最新的

### Q: 回答速度慢？

**影响因素**:
- LLM 模型大小（大模型推理慢但质量高）
- GPU 负载（多人同时使用时需要排队）
- 文档数量（大量文档会增加检索时间）
- 网络延迟（使用远程 API 时）

**优化建议**:
- 使用较小的模型（如 DeepSeek-R1-Distill-Qwen-7B）
- 降低知识库中文档数量
- 联系管理员检查 GPU 负载

### Q: 如何确保数据安全？

**系统保障**:
- **纯本地部署**: 所有数据存储在您自己的服务器上，无数据出网
- **JWT 认证**: 每次 API 请求都需要有效令牌
- **角色权限**: 不同角色有不同的操作权限
- **审计日志**: 所有操作都有完整记录（谁、何时、做了什么）
- **知识库隔离**: 不同知识库之间数据隔离

### Q: 出现错误提示怎么办？

常见错误及处理：

| 错误提示 | 含义 | 处理 |
|---------|------|------|
| "认证失败" | Token 过期或无效 | 重新登录 |
| "服务不可用" | 后端服务异常 | 联系管理员 |
| "文件过大" | 超过 50MB 限制 | 压缩或拆分文件后重试 |
| "不支持的文件类型" | 格式不在支持列表中 | 转换格式后重试 |
